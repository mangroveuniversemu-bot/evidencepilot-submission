# Scope and IP boundary

This repository is prepared for a public hackathon submission. Its submitted
source and fixtures are deliberately separated from private or unpublished work.

## What is in this repository

- Original code written for this submission.
- Synthetic datasets generated by `scripts/build_examples.py`.
- A Bell/CHSH scenario built from textbook material and the publicly described
  experiments recognised by the 2022 Nobel Prize in Physics (Aspect, Clauser,
  Zeilinger).
- The Collatz conjecture as a finite-verification test case, chosen because it
  is famous, public, and cheap to compute.

## What is deliberately not in this repository

- Measured or unpublished experimental data of any kind.
- Any unfiled or in-preparation research method, formulation, or derivation.
- Any private algorithm, decision policy, benchmark, or claim-generating
  mechanism from a separate project.
- Any third-party or confidential dataset.

The scenario is designed to *look like* real research operations while
containing nothing that is not already public. A judge can read every byte in
`examples/` and learn nothing except how the agent behaves.

## Why the data is synthetic

Beyond the IP boundary, synthetic data is the right technical choice here:
each package is constructed to exhibit one specific, documented failure mode
exactly, which makes the adversarial suite a real test rather than a
demonstration. `scripts/build_examples.py` builds counts from target
correlation values and writes self-consistent hashes, so a regenerated package
still reproduces the same verdict.

## Licensing

MIT (see `LICENSE`). MIT was chosen over Apache-2.0 deliberately: it grants
the copyright permissions a hackathon submission needs without an express
patent grant, which keeps this demo repository cleanly separated from any
patent position held elsewhere. If an express patent grant is preferred,
switching to Apache-2.0 is a one-file change and the code carries no
dependency on the choice.

## Reuse boundary for later projects

Components originating here — `VerdictCard`, `EvidenceCertificate`,
`ExecutionTrace`, `EscalationPolicy` — are MIT-licensed and may be carried
into later work. `docs/lineage.md` records where each one came from so that a
later submission can state precisely what was pre-existing and what was new.
